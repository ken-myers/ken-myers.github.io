{% include gallery.html photos=favorites %} {%- endif -%} {%- comment -%} One chronological pass over every photo (newest first; undated last). A new section starts whenever the timeline "key" changes. The key is, in priority: - segment -> free-text timeline heading (e.g. "back to nyc again"). This is a SEPARATE axis from tags/albums: the same place can recur in the timeline under different segment titles while still living in one album via its `tags`. Rendered as plain text (a segment is "not necessarily a tag", so it doesn't link anywhere). - trip -> legacy named trip; rendered as a heading linking to its album. - (dated) -> key "unnamed": a contiguous run of loose dated photos; range only, no title. - (undated)-> key "undated": no date; sorts last; header "undated". Each section's date range is computed from ITS OWN contiguous run (forward-scan the sorted list until the key changes) — not from every photo sharing the name, so a place that recurs shows the right span each time. A run that lives on a single day (a day trip) shows just that one date, not "date to date". {%- endcomment -%} {%- assign allphotos = site.photos | sort: "date" | reverse -%} {%- assign prevkey = "" -%} {%- for p in allphotos -%} {%- assign idx = forloop.index -%} {%- assign isfirst = forloop.first -%} {%- assign islast = forloop.last -%} {%- if p.segment -%} {%- assign key = p.segment -%} {%- assign kind = "segment" -%} {%- elsif p.trip -%} {%- assign key = p.trip -%} {%- assign kind = "trip" -%} {%- elsif p.date -%} {%- assign key = "unnamed" -%} {%- assign kind = "unnamed" -%} {%- else -%} {%- assign key = "undated" -%} {%- assign kind = "undated" -%} {%- endif -%} {%- if key != prevkey -%} {%- unless isfirst %}{% endunless -%} {%- comment -%} run-local range: p is newest (desc sort); scan forward for the run's oldest {%- endcomment -%} {%- assign runmin = p.date -%} {%- assign inrun = true -%} {%- for q in allphotos offset: idx -%} {%- if q.segment -%}{%- assign qkey = q.segment -%} {%- elsif q.trip -%}{%- assign qkey = q.trip -%} {%- elsif q.date -%}{%- assign qkey = "unnamed" -%} {%- else -%}{%- assign qkey = "undated" -%}{%- endif -%} {%- if qkey != key -%}{%- assign inrun = false -%} {%- elsif inrun -%}{%- assign runmin = q.date -%}{%- endif -%} {%- endfor -%} {%- assign rmin = runmin | date: "%m-%d-%Y" -%} {%- assign rmax = p.date | date: "%m-%d-%Y" -%} {%- capture rangehtml -%}{%- if rmin == rmax -%}{{ rmin }}{%- else -%}{{ rmin }} to {{ rmax }}{%- endif -%}{%- endcapture -%} {%- if kind == "segment" -%}
